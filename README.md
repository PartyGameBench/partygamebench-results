# PartyGameBench — Public Model Outputs, Triage Reports & Scores (CC0-1.0)

[![License: CC0-1.0](https://img.shields.io/badge/License-CC0_1.0-lightgrey.svg)](https://creativecommons.org/publicdomain/zero/1.0/)

This repository archives the public, open-data artifacts produced by **PartyGameBench** across supported open-API game engines:

- **oblox/ (RGBench)**:
  - S01_pilot/: Season 01 (*Vertical Decay / Crumbly Platforms*) task specification, shared SDK contract, model-generated Luau cartridges (aw/ verbatim output + epaired/ conservative triage output + epair_report.json), static audit reports, and season score tables.
- **minecraft/ (MCBench)**:
  - Reserved directory for Minecraft open-API party game benchmark seasons.
- **leaderboards/**:
  - Cross-season and cross-game JSON schemas and aggregated Bradley-Terry / Elo ratings (lpha_native native execution multiplier, Engineering Health, Gameplay Fun, Visual Style Fidelity, and Composite Score).
